# Demo 设计说明 — 2026-08-02

## 1. Demo 名称

换挡 Downshift —— 模型迁移的「按成功任务计价」离线复盘台

## 2. 一句话定位

面对「便宜三倍的新模型」，用你自己的 agent trace 重放，算清「每个**成功**任务到底省不省钱、掉不掉成功率」，再给可执行裁决——而不是被 $/token 单价和厂商榜单牵着走。

## 3. 目标用户

运营 agent 车队 / Coding agent 流水线的技术负责人、平台/基础设施工程师、为 LLM 账单负责的人。

## 4. 使用场景

DeepSeek-V4-Flash-0731 这类「只改后训练、便宜三倍」的模型发布，老板问「我们要不要换」。用户打开换挡，选一个自家工作负载，立刻看到「厂商话术的表面单价」与「诚实的每成功任务成本 + 成功率变化」的强烈反差，拿到「值得换 / 有条件换 / 先修再换 / 别换」裁决与补救项，并用盈亏平衡滑杆理解「成功率掉到多少这笔迁移就亏了」。

## 5. Demo 策略分型（重要）

- 本机会属于：☑ 抽象 / CLI / API / 基础设施类产品（模型迁移决策，本质是离线计算 + 决策）
- 采用的演示方式：纯前端「**模拟体验 + 价值可视化**」
  - **before/after 对比**：表面单价（厂商话术，划掉）vs 诚实每成功任务成本（我们的增量）。
  - **逐项复盘台账**：把「每任务成本」到「每成功任务成本」的翻转过程逐行拆开。
  - **盈亏平衡交互**：滑杆调 B 的成功率 / 步数膨胀，实时看裁决翻转与盈亏平衡成功率线。
- 演示的是**我们分析出的创新切入点**（按成功任务计价的迁移决策），不是 DeepSeek 模型本身的克隆，也不是 08-01 风洞（运行时成本倍率）的重复。

## 6. 核心流程（3 分钟内看懂价值）

1. 进入 **换挡台**：默认选中「编码 PR 车队」，顶部一行厂商话术大字「输出单价 −87%！」被划掉，右侧诚实读数「每成功任务成本 −75%、成功率 82%→80%」，中间一张大裁决卡「值得换」。
2. 切换工作负载卡片（4 个），看裁决在「值得换 / 有条件换 / 先修再换 / 别换」之间变化——尤其「实时语音 agent」：表面 −25%，诚实 **+35%（反而更贵）→ 别换**，一眼击穿「单价便宜」的幻觉。
3. 进 **逐项复盘**：看这个工作负载从「每任务成本（确实更便宜）」到「每成功任务成本（可能不便宜）」是怎么一行行翻转的，以及有效输入单价（计入真实缓存命中）、步数膨胀、啰嗦度的贡献。
4. 进 **盈亏平衡**：拖动「B 成功率」「B 步数膨胀」两个滑杆，实时看诚实成本比 r、裁决卡颜色翻转，以及「盈亏平衡成功率线」——直观理解「便宜是有条件的」。

## 7. 页面结构（<= 3 个主要页面 / Tab）

- 页面 1：**换挡台（Downshift Desk）**——工作负载选择 + 厂商话术(划掉) vs 诚实读数 + 大裁决卡 + 补救项。
- 页面 2：**逐项复盘（Replay Ledger）**——指标对照表（A 现有 / B 候选 / 变化）+ 每成功任务成本堆叠柱（输入/输出分解）+ vanity vs honest 对比。
- 页面 3：**盈亏平衡（Break-even Explorer）**——两个滑杆（B 成功率、B 步数膨胀）+ 实时裁决卡 + SVG 成本比曲线 + 盈亏平衡成功率标注。

## 8. 关键交互

- 工作负载切换（4 张卡片，点击即换全局 selected）。
- 裁决卡按 4 档裁决变色（值得换=绿 / 有条件换=蓝 / 先修再换=橙 / 别换=红）。
- 盈亏平衡两个受控滑杆，driven by 同一确定性引擎，实时重算 r / 成功率 / 裁决 / 曲线。
- 全局「厂商话术 vs 诚实」对照贯穿三页，强化「$/token 是虚荣指标」。

## 9. 使用的 mock 数据

全部为 mock，不接真实后端/外部 API。结构（见 `src/data/workloads.ts`）：
- 每个工作负载含 A（现有模型）与 B（候选模型）的：价目 `{inputMiss, inputHit, output}`（$/百万 token）、`baseInTok/baseOutTok`（每任务基线 token）、`cacheHit`（缓存命中率）、`success`（重放成功率）、`stepMult`（步数相对 A 的倍率）、`verbosity`（输出啰嗦度倍率），以及产品 `floor`（可上线成功率底线）。
- 4 个工作负载：编码 PR 车队 / 长上下文文档 QA / 工具编排客服 / 实时语音 agent，覆盖 4 档裁决。
- A/B 价目参考报告披露的 V4-Pro 与 V4-Flash 量级（Flash：$0.14 未命中 / $0.0028 命中 / $0.28 输出），但**数值为演示用途，非实测跑分**（首屏明确声明）。
- 计算逻辑集中在 `src/logic/engine.ts`（确定性纯函数：`effInput / costPerTask / analyze / classifyVerdict / breakEvenSuccess`），数值已用一次性脚本预校验。

## 10. 明确不做什么

- 不做登录 / 用户系统
- 不接数据库 / 支付 / 外部私钥 / 真实 API / 真实模型调用
- 不做生产级后端
- 不声称数值为真实跑分——首屏与页脚均标注「方法论演示 · 数值为 mock」

## 11. 成功体验标准

- 用户 3 分钟内能说出：它解决什么（要不要换更便宜的模型）、怎么用（重放你的 trace，看每成功任务成本而非单价）、增量在哪（厂商中立、耦合成本×能力、给可执行裁决）。
- 至少看到一个「表面便宜、其实更贵（别换）」的诚实反例，理解「单位 token 便宜 ≠ 单位任务便宜」。
- 明白这不是 DeepSeek 的克隆、也不是 08-01 风洞（运行时倍率）的重复。

# 召算 Zhàosuàn — 「AI 员工」运行时成本 × 毛利推演沙盘

> Product Opportunity Lab · 2026-08-24 · 纯前端静态 Demo（Vite + React + TypeScript）

在给 AI agent 配「电脑」、给产品定价**之前**，把四种运行时架构下的月账单、毛利随用户规模的悬崖、以及「隔离 / 可靠 / 单位成本」不可能三角，用可调滑块与图表一次性算清、看明白。厂商中立，**不运行任何 agent、不接任何云**，卖的是判断而不是运行时。

## 它解决什么问题

给 agent 配「电脑」的成本是**用量驱动**，定价却常是**平价订阅**（如 $9/月）——两者错配会让毛利在某个用户规模**断崖式转负**。solo founder 在写第一行基础设施代码前，无法预判、无法横向比较架构、无法验证定价是否可持续。选错架构=重写整层基础设施，极贵且不可逆。

## 三个页面

1. **沙盘**：拖动用户行为画像滑块（MAU、任务量、任务时长、闲置比、并发峰值、鲸鱼比例、定价），实时看四种架构（自建 VPS 常驻 / 本地客户端 / 云端常驻 / 边缘按需召唤）的毛利率、月成本、冷启动、毛利转负点；配「毛利 × 规模曲线」与「不可能三角雷达」，并给出脚本化「顾问解读」。附 3 个一键场景剧本。
2. **架构对比**：切换创业画像，横向 before/after 对比报告里三条真实路线——本地（AutoClaw 路子）/ 云端常驻（Epho 路子）/ 边缘按需（Construct 路子），看甜点如何随场景漂移。
3. **方法论 & 透明度**：成本模型公式、以及「报告事实 vs 我的建模假设」透明声明与免责。

## 运行方式

```bash
# 安装依赖
npm install

# 本地开发（默认 http://localhost:5173 ）
npm run dev

# 生产构建（产物在 dist/）
npm run build

# 预览构建产物
npm run preview
```

## 技术说明

- Vite + React + TypeScript；`vite.config.ts` 设 `base: './'`，可部署到任意 GitHub Pages 子目录。
- 图表为手写 SVG（无第三方图表库），依赖最小、构建稳定。
- 成本模型在 `src/lib/costModel.ts`，为**确定性公式**；参数为**建模假设**（非真实云报价，见方法论页声明）。
- 「顾问解读」（`src/lib/advisor.ts`）为**脚本化模板生成**，示意真实产品会用 LLM 给出的自然语言诊断，**非真实 LLM 调用**。

## 明确不做

- 不做登录 / 用户系统；不接数据库 / 支付 / 外部私钥 / 真实 API / LLM。
- 不真正运行任何 agent、不真正开任何云机器；所有数据 mock。
- 不声称成本数字为真实云报价。

## 与 Construct Computer 的本质区别（不照抄声明）

Construct 是「**跑** agent 的运行时」（Cloudflare 边缘、按 tool-call 计费）；召算是「**选 / 算** 运行时的决策沙盘」（厂商中立、纯前端、上线前）。阶段（运行 vs 决策）、形态（服务 vs 沙盘）、绑定（锁边缘 vs 中立）三点本质不同。

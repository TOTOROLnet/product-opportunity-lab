# 绕行 Ràoxíng — 模型路由「回退税」诊断台

> 2026-08-22 · product-opportunity-lab 每日机会 Demo · 纯前端静态原型（Vite + React + TypeScript）

接了「便宜模型优先 + 达不到质量门槛就自动 fallback 到大模型」的 LLM 网关（如 Router by Ramp / OpenRouter / 自建网关），
成本仪表盘显示「省了 67%」——**但其中约 14% 的「节省」站不住脚**。

**绕行**不做又一个路由网关，而做网关**看不见的那一层**：

- **失败特征聚类（failure-signature clustering）**：把回退与静默降级的请求按失败特征聚成簇（超上下文截断 / 工具 JSON 格式错 / 边界逻辑错·静默 / 语气串味·静默 …）。
- **账面 vs 真实 的诚实记账**：把**回退税**（便宜调用先失败再打大模型 = 双付 + 尾延迟）与**静默质量债**（便宜模型看似成功、实则输出悄悄变差、仍被记成省钱）从省钱数字里拆出来。
- **按请求类别的改道建议**：只对系统性失败（失败率 ≥ 40%）的类别改道到大模型，真正在省钱的健康类别继续走便宜——内置「别矫枉过正」守卫。

## 三个页面

1. **① 回退地图**：反直觉的诚实大标题「账面省 67% · 其中约 14% 是幻觉」+ 现状总账 + 失败特征聚类卡片（静默降级标红）。
2. **② 改道方案**：三个预设（现状 / 推荐改道 / 全部改道）+ 按类别改道开关，实时重算成本 / 回退剩余 / 质量债剩余 / 延迟；可自证「把健康类别改道 = 白花钱」。
3. **③ 对照 & 说明**：三方对照条（全大模型 / 便宜+回退 / 绕行后，随 Tab ② 开关实时联动）+ 透明公式框 + 非照抄声明 + 诚实声明。

## 本地运行

```bash
npm install
npm run dev      # 本地开发（默认 http://localhost:5173）
npm run build    # 产物输出到 dist/
npm run preview  # 预览 build 产物
```

- `vite.config.ts` 已设 `base: './'`（相对路径），可部署到任意 GitHub Pages 子目录（`/<date>/`）。

## 数据与边界（全 mock）

- `src/data/traffic.ts`：6 类请求、共 50 条的 mock 网关流量（每类含便宜成功 / 回退 / 静默降级数、失败特征、示例请求）+ 成本/延迟常量。
- `src/engine.ts`：确定性纯函数——总账、账面/可信/幻觉节省、回退税、失败特征聚类、按改道开关重算、「只对严格系统性失败的类别改道」守卫。
- **不做**：登录 / 数据库 / 支付 / 密钥 / 真实 LLM / 真实网关日志 / 后端 / 外部 API；不路由任何真实流量、不调用任何模型。

## 诚实声明

Demo 的「回退 / 静默降级」标签是 mock 语料预置的。现实里「便宜模型看似成功、实则质量降级」极难自动判定，
需要 shadow eval / 启发式 / 抽样人审——这是真实产品的命门。绕行不假装已解决它，只把「一旦有了这些标签，
如何聚类、如何诚实记账、如何按类别改道」这套方法讲清楚。

## 非照抄

- 非 Router/OpenRouter（路由网关）克隆：绕行是它们的**诊断/归因层**，不路由真实流量。
- 非 LLM 可观测性（Helicone/Langfuse）：是**决策层诊断 + 诚实记账 + 改道模拟**，非日志留存。
- 非「换挡」（模型切换成本预检/裁决）重做：基因是**失败特征聚类 + 记账重构**，对象是**路由回退**而非模型切换；也不是 gate/审批/扫描器。

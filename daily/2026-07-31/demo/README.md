# 忆证 Yìzhèng — Agent 记忆的回忆信任闸（Recall Trust Gate）

> 2026-07-31 每日机会 Demo。纯前端静态原型（Vite + React + TypeScript），全部数据 mock，
> 不接后端 / LLM / 数据库 / 登录 / 支付 / 外部 API / 真实记忆库。

## 这是什么

现有的 agent 记忆产品（Liminal 的 Obsidian 库、FlowTask 的 skill.md、向量库、ChatGPT memory）
优化的是记忆的**存储、写入与召回**。但记忆会**过期、互相矛盾、来自一次随口一说**——
当 agent 拿着一条记忆去执行**真实动作**（退款/改单/发消息）时，没人回答：

> **"现在，该不该信这条记忆、该不该拿它动手？"**

**忆证** 就是这一层：与存储解耦，坐在任意记忆库之上，在 agent **动手之前**对每条被召回的记忆算并展示
`来源 × confirm 次数 × 时效衰减 × 矛盾`，综合成一个可解释的 trust 分数；低于阈值或违反治理政策就
**拦下改为人工复核**，而不是静默照做。并提供一个**对账台**做记忆的持续"对账与遗忘"。

- vs **Liminal**：它是"用户自持的记忆存储"；忆证不存记忆，是其上的信任/对账层。
- vs **FlowTask**：它是"写入门"（什么能进记忆）；忆证是"读取/使用门"（过期/矛盾了还能不能拿来动手）。
- vs **Prefactor**：它评"agent 的产出/动作"；忆证评"agent 依据的记忆/信念"，位置更上游。

## 三个页面

1. **① 动手前 · 信任闸**：agent 待执行动作 + 它依据的记忆证据卡（带 trust 徽标）+ gate 结论
   （PROCEED / HOLD / BLOCK）+「有忆证 / 无忆证」价值对比。
2. **② 记忆账本 · 对账台**：全部记忆表格 + 过滤；可退役 / 解决矛盾 / pin / 再确认，
   **即时重算 trust** 并回写信任闸结论。
3. **③ 溯源 · 信任拆解**：单条记忆的来源与冲突时间线、时效衰减曲线、trust 公式因子拆解。

## 本地运行

```bash
npm install
npm run dev      # 本地开发预览（默认 http://localhost:5173）
npm run build    # 产出到 dist/
npm run preview  # 预览 build 产物
```

## 3 分钟体验路径

1. 打开落在 **① 信任闸**：看到 agent 准备"自动退款 $500"，结论是 **BLOCK**（依据记忆 m1 过期且被新政策 m4 推翻，动作违反 m4）。
2. 切「无忆证 / 有忆证」开关，看两种世界的不同结局。
3. 去 **② 对账台**，对 m1 点「解决矛盾」（以新政策为准退役 m1），或对某条点 pin / 再确认，看 trust 与信任闸结论实时变化。
4. 回 **① 信任闸**点「以经理身份补齐审批」，看 BLOCK → PROCEED（人被拉进回路后放行）。
5. 任意记忆卡点进去 → **③ 溯源**，看它为什么是这个分数。

## 技术说明

- `src/data/memories.ts`：约 10 条 mock 记忆 + 场景，全部虚构。
- `src/logic/trust.ts`：确定性、可解释的 trust 与 gate 计算（无随机、无网络）。
- `vite.config.ts`：`base: './'`，保证部署到 GitHub Pages 的 `/<date>/` 子目录也能正确加载资源。

## 诚实边界

Demo 用确定性 mock 公式演示"信任层长什么样、价值在哪"，**不含**工业级语义矛盾检测与真实衰减学习。
它证明的是产品形态与价值，不是"已实现生产级记忆信任引擎"。

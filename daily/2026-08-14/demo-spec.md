# Demo 设计说明 — 2026-08-14

## 1. Demo 名称
说戏 Shuōxì —— 给「brief→成片」agent 用的导演改稿台

## 2. 一句话定位
不做视频生成；做生成之上的**导演改稿层**——按镜头给导演笔记、锁定已认可镜头、只重生成被点名的镜头，让「无时间线」的承诺在**改稿环节**依然成立。

## 3. 目标用户
已经在用 brief→成片 agent（Vizard / Omniwork / CapCut 智能剪等）、但卡在「初稿 80% 对、最后 20% 改不动」的创作者、营销与独立开发者。

## 4. 使用场景
用户拿到 AI 生成的一条口播短视频初稿：大方向对，但开头钩子太温、中间一段节奏拖、结尾 CTA 语气不对。他不想回时间线手剪，也不想整片重来丢掉满意的镜头——于是进「说戏」，对着 storyboard 逐镜说戏，锁住已认可的镜头，只重生成被点名的 2–3 个镜头，并在改动前后对比里确认「保留 X 镜、只重生成 Y 镜、省一次整片重烧」。

## 5. Demo 策略分型（重要）
- 本机会属于：☑ 可视化/交互类产品　□ 抽象 / CLI / API / 基础设施类产品
- 采用的演示方式：**直接做可点击交互 Demo**。用 storyboard 卡片模拟一条成片的镜头序列，导演笔记面板做镜头级说戏，改动预览页做 before/after 的 keep-vs-regenerate diff 与成本/保留度可视化。
- 演示的是**我们分析出的创新切入点（导演改稿层）**，不是被参考产品 Vizard 的生成流水线克隆——Demo 里**不生成视频**，只演示「改稿」这一层的交互与价值。

## 6. 核心流程
（用户从进入到「看懂价值」的主路径，3 分钟内可完成）
1. **看初稿（放映台）**：进入即看到 AI 生成的一条成片初稿 = 6 个镜头卡片（缩略占位图 + 口播文案 + 时长 + 节奏/情绪标签）。点「▶ 模拟放映」逐镜高亮回放，建立「这是一整条片子」的直觉。
2. **说戏（导演台）**：逐镜给导演笔记——自然语言（如「钩子再抓一点，前 2 秒抛冲突」）+ 快捷控件（节奏 慢/保持/快、情绪 -/+、强调、语气）。满意的镜头点「🔒 锁定」保护起来。系统实时把镜头标为「🔒 锁定 / ✎ 待改 / — 未动」。
3. **看改动（改动预览）**：点「预览改动」，左右对比初稿 vs 新方案：只对「待改」镜头做重生成（mock 引擎按笔记改写文案/节奏/情绪），锁定与未动镜头**逐字保留**；顶部给「保留 X 镜 / 重生成 Y 镜 / 相对整片重来省下 Z 次镜头生成」的价值可视化。确认后应用，回到放映台看收敛。

## 7. 页面结构（<= 3 个主要页面 / Tab）
- 页面 1：**放映台（Draft）**——成片初稿的 storyboard + 模拟逐镜放映 + 每镜状态。
- 页面 2：**导演台（Direct）**——镜头级导演笔记 + 快捷控件 + 锁定；这是产品的核心界面。
- 页面 3：**改动预览（Diff）**——before/after 对比 + keep/regenerate 高亮 + 成本/保留度可视化；并附「说戏 vs 整片重来 vs 回时间线」的 before-after 价值对比。

## 8. 关键交互
- 镜头级选择与说戏：点卡片选中镜头，写笔记 + 调控件；空笔记 + 无控件变化的镜头默认「未动」。
- 锁定语义：锁定镜头在预览中**绝不改动**（可视化里显式标「保留原样」），演示「保护已认可镜头」这一核心承诺。
- mock 重生成：一个脚本化「导演引擎」根据笔记与控件，对文案做可解释的确定性改写（如「节奏=快」→ 缩短句子/加动词；「情绪+」→ 加强钩子词），并给出「改了什么、为什么」的说明，避免黑盒。
- 价值可视化：进度条/计数显示保留度与「省下的重生成镜头数」；一键在「说戏 / 整片重来 / 回时间线」三种改稿路径间切换看代价对比。

## 9. 使用的 mock 数据
（说明数据来源与结构，全部为 mock，不接真实后端/外部 API）
- `mockDraft`：一条口播短视频初稿，6 个 `Shot`（id、缩略色块/emoji、口播文案 script、时长 sec、节奏 pace、情绪 energy、visualNote）。
- `directorEngine`：纯前端确定性函数 `regenerate(shot, note, controls) → newShot + rationale[]`，用规则模拟「按导演意图改写镜头」，全部本地计算，无网络。
- 预置示例笔记与「一键填充导演意图」按钮，方便 3 分钟内跑通主路径。
- 所有缩略图为 CSS/emoji 占位，无外部图片/视频资源。

## 10. 明确不做什么
- 不做登录 / 用户系统
- 不接数据库 / 支付 / 外部私钥 / 真实 API / LLM / 视频生成模型
- 不做生产级后端
- 不真的生成或渲染视频（Demo 只演示「改稿层」的交互与价值可视化，镜头以 storyboard 卡片表示）

## 11. 成功体验标准
- 用户 3 分钟内能说出「它解决什么问题、怎么用、增量在哪」：改稿不再是「回时间线」或「整片重来」，而是**镜头级说戏 + 锁定保留 + 只重生成被点名镜头**。
- 首屏就能看出这是「改稿层」而非又一个视频生成器。
- 锁定→预览能直观看到「已认可镜头被逐字保留、只有待改镜头变化」，且给出省下的重生成成本。

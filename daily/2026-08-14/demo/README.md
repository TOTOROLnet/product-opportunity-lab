# 说戏 Shuōxì —— 给「brief→成片」agent 用的导演改稿台（Demo）

> 一句话：**不做视频生成，做生成之上、厂商中立的「改稿 / 导演层」。**
> 把视频迭代从「回时间线手剪」或「整片重来」，重构为：**按镜头给导演笔记 + 锁定已认可镜头 + 只重生成被点名的镜头 + 改动前后 keep-vs-regenerate diff + 成本/保留度可视化。**

## 这是什么 / 解决什么问题

现在的「brief→成片」视频 agent（如 Product Hunt 雷达 2026-08-13 报告里的 **Vizard Agent**）能一句话出初稿，卖点是「无时间线 UI」。但**改稿闭环**才是留存命门——初稿常常「大方向对、局部不对味」，此时只有两条烂路：

- **回时间线**手剪：否定了「无时间线」的全部价值，还得会剪辑；
- **整片重生成**：丢掉本来满意的 80%，再烧一次生成成本，结果还可能连好的地方都变了。

「说戏」提供**第三条路**：像导演对剪辑师说戏一样，**逐镜**给意图、**锁定**已认可的镜头、**只重生成**被点名的那几个，其余逐字保留。

> 与被参考产品的本质区别：Vizard = 生成流水线 + 一个聊天框改稿；说戏 = 生成之上的**导演层**（镜头级结构化笔记 + 显式锁定/保留语义 + 可解释的 keep/regenerate diff + 成本可视化）。**不同的活（改稿 vs 生成）、不同的交互原语（导演笔记 vs 聊天）、不同的价值（保留 + 精确 + 省成本）。**

## 三个页面（3 分钟主路径）

1. **① 放映台**：看一条由 agent 自动产出的口播广告初稿（6 个镜头卡片），可「▶ 模拟放映」逐镜回放。
2. **② 导演台**（核心界面）：选中镜头 → 写自然语言导演笔记 + 点快捷控件（节奏 / 情绪 / 强调 / 语气）→ 满意的镜头点 🔒 锁定。右侧实时预览「导演引擎会怎么改这一镜」（tracked-changes diff + 逐条原因）。点「✨ 一键填充导演意图」可载入一个真实改稿场景。
3. **③ 改动预览**：左右对比初稿 vs 提案，只有「待重生成」镜头被改写，锁定/未改动镜头 100% 保留；顶部给「保留度 / 重生成镜头数 / 相对整片重来省下的生成」价值卡片，并附「说戏 vs 整片重来 vs 回时间线」三路对比。应用后回放映台看收敛。

## 本地运行

```bash
npm install
npm run build     # 产出 dist/（tsc -b && vite build）
npm run dev       # 本地开发预览
npm run preview   # 预览 build 产物
```

- 技术栈：Vite + React + TypeScript。
- `vite.config.ts` 设 `base: './'`（相对路径），保证部署到任意 GitHub Pages 子目录（`/<date>/`）都能正确加载资源。

## 诚实边界（这是 Demo，不是产品）

- **纯前端静态**，全 mock：一条口播短视频初稿 + 一个脚本化「导演引擎」（`src/engine.ts`）。
- **不接** LLM / 视频生成模型 / 后端 / 数据库 / 登录 / 支付 / 密钥 / 外部 API。
- 「导演引擎」用**确定性规则**模拟「按导演意图重生成一个镜头」（剪铺垫词 / 插冲击开场 / 高亮强调短语），并给出「改了什么、为什么」的可解释说明——它演示的是**理想形态**。真实产品里，这一层需要上游生成 agent 暴露**镜头级重生成 + 稳定 seed/锁定**能力；现实中很多生成器只能整片重来，「只重生成被点名镜头」可能退化为「局部近似」，这是主要落地风险（见 `../opportunity.md` §6）。
- Demo 里镜头以 storyboard 卡片（色块 + emoji 占位）表示，**不真的渲染视频**。

```
  engine.ts              # 导演引擎：statusOf / regenerate / effectiveShot（确定性、可解释）
  types.ts               # Shot / DirectorNote / DiffToken 等类型
  data/mock.ts           # mock 初稿（6 镜）+ 预置导演意图
  components/
    DraftTab.tsx         # ① 放映台
    DirectTab.tsx        # ② 导演台（核心）
    DiffTab.tsx          # ③ 改动预览
    shared.tsx           # StatusPill / ShotThumb / DiffText 等复用件
  index.css              # 暗色 UI 样式
```

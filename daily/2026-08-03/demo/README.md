# 分寸 Poise — 个人 AI 代表「上岗前的分寸彩排 + 授权边界」台

> 2026-08-03 产品机会实验室 Demo。纯前端静态原型（Vite + React + TypeScript），全部数据为 mock，**不接后端 / LLM / 数据库 / 登录 / 支付 / 外部 API / 真实电话邮件**。

## 这是什么

个人 AI 代表（Zinley / Vela / Pally 式）能拥有独立号码、邮箱、电脑，替你打电话、回邮件、跟进事务。它们的**生死不在功能多少，而在信任设计**——什么时候替你行动、什么时候回来找你。今天没人让用户在真人电话/邮件发生**之前**，先把这条边界**教清楚、看明白、调到安心**。

**分寸 Poise** 就是这块空白：一个厂商中立、自己**不执行任何对外动作**的「上岗前彩排台」。

## 三步核心流程（3 分钟看懂）

1. **① 彩排台**：逐张翻真实情境卡（供应商改约、猎头报价、房东维修、朋友借钱、订阅涨价、家人来电、陌生销售…），看代表"打算怎么做"，你四选一拍板：**放手让它做 / 拟稿待批 / 先问我 / 绝不可碰**，顺手判"像不像我说的话"。右侧分寸画像实时长出来。
2. **② 分寸画像**：把零散拍板合成一张可读可调的契约——**话题 × 风险** 的授权刻度热力矩阵 + 语气卡 + 红线清单。**点任意格子**即可就地调整。
3. **③ 一周回放**：用当前画像回放 15 条 mock 互动，诚实显示"替你处理 / 拟稿 / 退回 / 拦下"分布，高亮**差一点出格**的几件，一键"收紧这条"后**实时重算**，并对比初始默认 → 当前。

## 确定性引擎（可复算，无随机）

- `src/logic/engine.ts`：授权刻度随风险单调收紧（`cellAutonomy`）、出格贴近度 `overstepRisk = 授权数值 × 风险权重`、阈值 `OVERSTEP_THRESHOLD = 6`、`classifyWeek` 回放汇总、`tightenTopic` 收紧、`profileArchetype` 画像性格。
- 默认画像回放：替你处理 6 / 拟稿 6 / 退回 3 / 拦下 0，**4 件差点出格**；收紧 报价谈判 + 维修准入 后 → **0 件出格**，画像从"偏放手型"变"偏协作型"。

## 运行

```bash
npm install      # 安装依赖
npm run dev      # 本地开发（默认 http://localhost:5173）
npm run build    # 生产构建，产物在 dist/
npm run preview  # 预览构建产物
```

## 目录

```
src/
  App.tsx                  # 三 Tab 主框架 + 状态
  types.ts                 # 领域类型
  data/situations.ts       # mock：情境卡 / 一周互动 / 默认拍板 / 文案
  logic/engine.ts          # 确定性授权引擎（纯函数、可复算）
  components/
    RehearsalView.tsx       # ① 彩排台
    ProfileView.tsx         # ② 分寸画像（可点击调整的热力矩阵）
    ReplayView.tsx          # ③ 一周回放（差点出格 + 收紧重算 + 对比）
    shared.tsx              # 配色 / 徽章 / 占比条 / 图例
  index.css                # 暗色主题样式
```

## 明确不做

不做登录 / 用户系统；不接数据库 / 支付 / 外部私钥 / 真实 API / 真实电话 / 真实邮件；不持有任何真实号码；不代表用户执行任何对外动作。演示的是"上岗前的信任校准"这一**创新切入点**，不是任何执行型分身产品的克隆。

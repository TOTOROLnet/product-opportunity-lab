# Demo 设计说明 — 2026-08-03

## 1. Demo 名称
分寸 Poise —— 个人 AI 代表「上岗前的分寸彩排 + 授权边界」台

## 2. 一句话定位
在你让一个个人 AI 代表用你的名义打电话/回邮件之前，先用真实情境把它"彩排"一遍，合成一张可读可编辑的「分寸画像」，再回放一周互动看清"它会替你做多少、退回多少、差点出格几件"——厂商中立，自己不打任何真实电话、不发任何真实消息。

## 3. 目标用户
正在用或考虑用个人 AI 代表（Zinley/Vela/Pally 式）的个人、自由职业者、小团队主理人：想省下电话/排期/跟进的时间，但极度介意 AI "以我名义"出格。

## 4. 使用场景
分身上岗前的"信任一跃"：用户面对一个能对外行动的代表，不知道它会在什么情况下擅自答应事、什么情况回来找我。Poise 让用户在真人被打扰前，先把自己的分寸教给它、并预览一周后果。

## 5. Demo 策略分型（重要）

- 本机会属于：**■ 可视化/交互类产品**（□ 抽象/CLI/基础设施类）
- 采用的演示方式：直接做**可点击交互 Demo**。核心是"情境卡拍板 → 实时合成分寸画像 → 一周后果回放 + 收紧重算"三段闭环，全部前端确定性计算。
- 演示的是我们分析出的**创新切入点（上岗前的信任校准与后果预演）**，不是 Zinley 的克隆（Poise 不持号码、不执行任何对外动作）。

## 6. 核心流程（3 分钟内可完成）
1. **进入「彩排台」**：逐张翻真实情境卡（供应商改约、猎头报价、房东维修、朋友借钱、订阅涨价自动续费、家人紧急来电、陌生销售…）。每张卡显示"代表打算怎么做（用你的口吻拟的动作）"，你四选一拍板：**放手让它做 / 拟稿待批 / 先问我 / 绝不可碰**，并顺手判"像我 / 不像我"。右侧「分寸画像」随手实时长出来。
2. **看「分寸画像」**：把零散拍板合成一张可读契约——按 话题×对象×风险 的**授权刻度热力矩阵** + 语气卡 + 绝不触碰红线。可直接在此调某条刻度。
3. **跑「一周回放」**：用当前画像回放 ~15 条 mock 互动，诚实显示分布（替你处理/拟稿待批/退回拍板/直接拦下）+ 时间线；高亮"**差一点出格**"的几件（画像允许它做、但贴近你红线/高风险），一键"收紧这条"→ 分布与出格数**实时重算**，并给出收紧前后对比。

## 7. 页面结构（<= 3 个主要页面 / Tab）
- 页面 1「彩排台 Rehearsal」：情境卡流 + 四档授权拍板 + 像我/不像我 + 右侧实时画像雏形与进度。
- 页面 2「分寸画像 Profile」：授权刻度热力矩阵（话题×风险）+ 语气卡 + 红线清单，可编辑；一句话解读"你是个什么分寸的人"。
- 页面 3「一周回放 Replay」：一周互动时间线 + 四类分布条 + "差一点出格"高亮卡 + 一键收紧 + 收紧前后对比。

## 8. 关键交互
- 四档授权拍板（放手/拟稿待批/先问我/绝不可碰）实时喂给确定性引擎，更新话题级授权刻度与红线。
- 授权刻度矩阵单元格可点选调档，立即影响回放。
- 回放里"差一点出格"卡的"收紧这条"按钮：把该话题降一档 → 全量重算分布 + 出格数，展示 before/after。
- 全程无网络请求、无外部 API、无真实动作。

## 9. 使用的 mock 数据（全部虚构，不接真实后端/外部 API）
- `situations`：~8 张彩排情境卡，字段含 话题(topic)、对象(counterparty)、风险档(stakes)、代表拟做的动作文案(proposedAction)、口吻样例(voiceSample)。
- `weekInteractions`：~15 条一周 mock 互动，字段含 话题、对象、风险、时间、简述。
- `topics/stakes` 枚举：排期改约 / 报价谈判 / 维修准入 / 人情借钱 / 订阅账单 / 家人紧急 / 陌生销售 / 客户跟进 等；风险档 低/中/高。
- 引擎把用户拍板合成 `profile`（每个话题一个授权档 + 若干红线），`classify(interaction, profile)` 输出 处理/拟稿/退回/拦下 + "出格贴近度" margin。

## 10. 明确不做什么
- 不做登录 / 用户系统。
- 不接数据库 / 支付 / 外部私钥 / 真实 API / 真实电话 / 真实邮件。
- 不做生产级后端；不持有任何真实号码；不代表用户执行任何对外动作。
- 不超过 3 个主要页面；全部数据 mock。

## 11. 成功体验标准
- 用户 3 分钟内能说出：它解决什么（分身上岗前把信任边界讲清+看清后果）、怎么用（拍板情境→得到分寸画像→回放一周）、增量在哪（把"出事再调的被动开关"变成"事前可见、可练、可调、可预览后果"的分寸契约）。
- 拍板能实时改变画像；回放能诚实显示分布并高亮"差点出格"；收紧一条能看到分布随之变化——证明这是"可校准的信任"，而非概念包装。

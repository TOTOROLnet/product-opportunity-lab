# Demo 设计说明 — 2026-08-13

## 1. Demo 名称
顺口 Shùnkǒu — 母语差距教练（Native-Gap Coach）

## 2. 一句话定位
从你的真实英文产出里，聚类出让你"不地道"的那几个**反复出现的习惯**，做成一张会随练习**可见收敛**的个人口音图谱，再精准补掉——**不碰发音**，只做发音之上的地道度。

## 3. 目标用户
CEFR B1–B2、在跨国团队每天用英文写 Slack/邮件、开会发言的中文母语者（开发 / PM / 设计等）。"能被听懂但一直不地道"，高意图、愿意付费。

## 4. 使用场景
用户就一个真实工作场景（跟同事改约 PR 评审、会上婉拒不合理 deadline、给下属正面+建设性反馈）自由地写/说一段英文 → 立刻看到"母语者会怎么说"以及**差在哪、属于哪类习惯** → 多次产出后看到自己的**个人习惯图谱** → 做**只针对这些习惯**的间隔微练习 → 图谱收敛。

## 5. Demo 策略分型（重要）

- 本机会属于：☑ 可视化/交互类产品　□ 抽象 / CLI / API / 基础设施类产品
- 采用的演示方式：**直接做可点击交互 Demo**。核心价值链（真实产出 → 母语改写差距 → 个人习惯图谱 → 精准补差练习 → 收敛）全部可交互，并用 before/after 直观展示增量。
- AI 能力用**脚本化"模拟 AI 引擎"（simulated AI engine）**呈现，UI 内明确标注"演示用模拟引擎，真实产品接 LLM"，保持诚实（不假装是真模型）。
- 演示的是**我们分析出的创新切入点**（习惯级、从自由产出发现、可收敛），**不是** Linforge/ELSA 的克隆——刻意**不做发音评分**。

## 6. 核心流程
（用户从进入到"看懂价值"的主路径，3 分钟内可完成）
1. 进入 **今日一练**：选一个真实任务卡 → 看到自己的 mock 产出（可编辑/切换样本） → 点"母语改写对齐"，左右对照 + **按习惯类型高亮差异**（词汇过窄 / 语法直译 / 缺地道搭配 / 语用生硬 / 冗余），点任一高亮看"为什么 + 母语说法"。
2. 切到 **我的口音图谱**：看到跨样本聚类出的 **Top 习惯（按频次排序）**，每条含"出现频次 + 实例列表 + 母语建议 + 收敛趋势条"。这一步是与逐条改错工具的本质区别——**把散点错误抽象成"你的习惯"**。
3. 切到 **补差牌组**：系统按你 Top 习惯**自动生成**只针对它们的间隔微练习；做 1–2 道 → 即时反馈（对/接近/再试） → **图谱里对应习惯的频次条实时下降**（before/after 可见收敛）。

## 7. 页面结构（<= 3 个主要页面 / Tab）
- 页面 1 · **今日一练 (Practice)**：任务卡选择 + 你的产出（可切样本/编辑） + "母语改写对齐"左右对照 + 按类型高亮的差异 + 点击详情。
- 页面 2 · **我的口音图谱 (Gap Map)**：Top 习惯排行（频次条 + 类型标签 + 实例 + 母语建议 + 收敛趋势），点习惯下钻看所有实例；顶部一句"你的地道度画像"总结。
- 页面 3 · **补差牌组 (Drill Deck)**：针对 Top 习惯自动生成的间隔微练习卡；作答 → 反馈 → 触发图谱收敛；底部"本周进度"（已收敛 / 待练 + 连续天数）。

## 8. 关键交互
- **差异高亮可点**：点高亮 span 弹出"原因（习惯类型）+ 母语说法 + 一句解释"。
- **习惯下钻**：点图谱里一条习惯，列出它在各任务里的所有实例。
- **练习即时反馈 + 图谱联动**：完成一道 drill，对应习惯的频次条动画下降，"本周进度"更新——让"收敛"可感。
- **样本切换**：今日一练可在 3 个 mock 任务样本间切换，体现"不同真实场景暴露同一批习惯"。
- 全局状态用 React 内存 state（无持久化后端）；"模拟 AI 引擎"是纯前端确定性函数，输入 mock 产出 → 输出改写/差异/习惯/练习。

## 9. 使用的 mock 数据
（说明数据来源与结构，全部为 mock，不接真实后端/外部 API）
- `tasks`：3 个真实工作场景任务（PR 改约 / 婉拒 deadline / 给反馈），每个含 `prompt`、`learnerOutput`（含多个不地道习惯）、`nativeRewrite`、`spans`（差异片段：原文/母语说法/习惯类型/解释）。
- `habits`：6 类习惯（very+形容词过度 / 让步直译 although...but / 缺 phrasal verbs / 语用生硬直接 / 冗余啰嗦 / 冠词时态实例级——后者刻意标为"低优先，非本产品重点"），每条含 `freqBefore`、`examples[]`、`nativeTip`。
- `drills`：针对 Top 习惯生成的微练习（题干 + 可接受的母语答案集合 + 讲解），作答后回写习惯 `freqAfter`。
- 全部为手工构造的、贴合中文母语者 B1–B2 的真实语料。**无任何真实 API / 语音 / 网络请求。**

## 10. 明确不做什么
- 不做登录 / 用户系统
- 不接数据库 / 支付 / 外部私钥 / 真实 API / 真实 LLM / 语音识别
- 不做生产级后端
- **不做发音 / 音素评分**（那是 ELSA/Linforge 的地盘，也非本产品切入点）——刻意划清界限，强化差异化
- 不做通用词表课程（区别于 Duolingo）

## 11. 成功体验标准
- 用户 3 分钟内能说出"它解决什么问题、怎么用、增量在哪"：**发音之上的地道度 / 从我的真实产出发现习惯 / 用间隔练习让习惯图谱收敛**。
- 能清楚感到与 Linforge（发音+词表）、Grammarly（逐条改错）、Duolingo（通用课程）的区别。
- 首屏即讲清价值（有一句话定位 + "模拟引擎"诚实标注），核心三步路径闭合、无死链、无空白页。

# Demo 设计说明 — 2026-07-28

## 1. Demo 名称
验己 Yànjǐ —— 个人健康「n-of-1 自我实验教练」

## 2. 一句话定位
把健康 AI 的「你该试试 X」变成一场为你一个人设计的对照实验，再用能识破安慰剂 / 均值回归 / 数据不足的诚实读数，告诉你「对你到底有没有用」。

## 3. 目标用户
已经戴手环 / 可能有 CGM / 做过血检、同时在用一个或多个健康 App 与健康 AI，被「你该……」建议淹没、分不清哪条对自己真有用的养生 / 长寿 / 认真健身人群。

## 4. 使用场景
用户从 Illume / ChatGPT Health 这类助手收到一条主动建议（如「少吃夜宵 / 补镁 / 冲冷水澡」），不知道对自己是否真有用；把建议交给验己 → 验己设计一场 n-of-1 实验 → 数据到位后给出**诚实读数**（有效 / 无效 / 数据不足 / 疑似安慰剂），并沉淀成「对我而言真正有效」的个人证据库。

## 5. Demo 策略分型（重要）

- 本机会属于：☑ 可视化 / 交互类产品（辅以「模拟数据回放 + 价值可视化」）
- 采用的演示方式：
  - 直接做**可点击交互 Demo**：选建议 → 看协议设计 → 回放基线/干预数据 → 得诚实读数。
  - 因为「个人健康数据」不能用真实数据，改用**预置 mock 时间序列 + 确定性读数引擎**做**模拟体验 + 价值可视化**（对读数是「确定性统计替身、非真实 AI 推断」如实标注）。
  - 关键价值瞬间用 **before / after 对比**呈现：**朴素解读（"降了 2bpm，有效！"）vs 验己诚实读数（"落在你自己的正常波动内，疑似均值回归，需延长"）**。
- 演示的是我们分析出的创新切入点——**建议的验证层与诚实读数**，不是 Illume（多源融合的主动建议助手）的克隆。

## 6. 核心流程（3 分钟内看懂价值）
1. 首屏读到定位与「主动建议 → 自我实验 → 诚实读数」的价值主张，看到 3 条来自健康助手的 mock 建议。
2. 选一条建议 → 进入**实验设计台**：验己自动生成 n-of-1 协议（假设、主指标、基线期 vs 干预期、由该指标噪声推出的所需天数、要控制/记录的混杂因素、成败线）。
3. 切到**读数**：回放基线 vs 干预的每日指标（CSS 条形/点阵），读数引擎给出结论卡（含置信度 + 判定理由），并展示**朴素 vs 验己**的 before/after 对比。
4. 切到**实验档案**：三场实验的诚实结论一览 + 「对你而言真正有效 / 无效 / 待定」的个人证据库摘要。

## 7. 页面结构（<= 3 个主要页面，用顶部 Tab 切换）
- 页面 1 · 实验设计台（Design）：3 条 mock 建议卡 → 选中后展开该实验的 n-of-1 协议详情。
- 页面 2 · 读数（Read-out）：选中实验的基线/干预数据回放 + 诚实读数结论卡 + 朴素 vs 验己 before/after。
- 页面 3 · 实验档案（Ledger）：三场实验汇总表（建议 / 主指标 / 结论 / 置信度）+ 个人证据库摘要 + 免责声明。

## 8. 关键交互
- 建议卡点击 → 高亮并在下方展开协议（假设 / 主指标 / 基线-干预窗口 / 所需天数 / 混杂因素 / 成败线）。
- 读数页：切换「朴素解读 / 验己读数」开关，同一份数据两种结论并排对比；hover/点击数据点看当日数值与所处期（基线/干预）。
- 档案页：点行可跳回对应实验的读数页。
- 全程无网络请求、无登录、无输入真实健康数据。

## 9. 使用的 mock 数据（全部为 mock，不接真实后端 / 外部 API）
三场预置实验，覆盖诚实读数的三种典型结论：
- **实验① 少吃夜宵 → 静息心率↓**：结论 **数据不足 / 疑似均值回归**（干预期均值仅比基线低 2.0bpm，小于基线日间波动 ~3.4bpm；且开实验那周基线偏高 → 疑似回归到均值）。
- **实验② 睡前补镁 → 深睡时长↑**：结论 **有效（中等置信）**（ABAB 设计：补→停→补→停，深睡在「补」段 ~79min、「停」段回落 ~63min，效应量约 2× 基线波动且反转一致）。
- **实验③ 冷水澡 → 主观精力↑**：结论 **疑似安慰剂 / 新奇效应**（主观自评第 1 周 +1.2、到第 3 周回落至基线；未盲、主观指标 → 证据弱）。
数据结构：每个实验含 `baseline[]`、`intervention[]`（②为分段 ABAB）、`metricType`(objective/subjective)、`direction`(higher/lower better)、`minDetectable`。读数引擎（`src/logic/engine.ts`）确定性计算：baselineMean/SD、delta、effectRatio=|delta|/SD、ABAB 反转一致性、均值回归/新奇效应启发式 → 结论 + 0–100 置信度 + 理由列表。所有数字预先用 esbuild 校验、与浏览器一致。

## 10. 明确不做什么
- 不做登录 / 用户系统 / 真实健康数据接入（手环 / CGM / 血检）。
- 不接数据库 / 支付 / 外部私钥 / 真实 API / LLM 调用。
- 不做生产级后端。
- 不提供医疗诊断或医疗建议（仅行为实验 + 诚实读数，页面明确免责声明）。
- 读数引擎是确定性统计替身，不声称是真实 AI 推断。

## 11. 成功体验标准
- 用户 3 分钟内能说出：验己解决什么问题（分不清建议对我有没有用）、怎么用（建议→设计实验→看诚实读数）、增量在哪（相对「只给建议」的 Illume，它给出**可复现的个人证据**并**敢说没用**）。
- 至少一场实验能让人直观感到「原来我以为有效的其实是噪声 / 均值回归」的顿悟瞬间（实验①的 before/after）。
- 首屏与档案页明确标注：非医疗建议、mock 数据、确定性读数替身。

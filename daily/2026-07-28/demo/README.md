# 验己 Yànjǐ · 个人健康 n-of-1 自我实验教练（Demo）

> 纯前端静态 Demo（Vite + React + TypeScript）。所有健康数据均为 **mock**，读数为**确定性统计替身**，非真实 AI 推断。**本产品只做行为实验与诚实读数，不提供医疗诊断或医疗建议。**

## 这是什么

健康 AI（如 Illume Labs、ChatGPT Health）已经会**主动**告诉你「你该试试 X」。
但一句通用建议对**你一个人**到底有没有用？个人健康指标噪声极大，用户凭「我感觉好像好点了」下结论，
极易被 **安慰剂 / 均值回归 / 新奇效应** 骗到。

**验己**坐在健康建议的**下游**，做两件现有产品不做的事：

1. **把建议变成实验**：为每条建议自动设计一份 n-of-1 对照实验协议（预登记假设、只盯一个主指标、
   基线期 vs 干预期、由你自己的指标噪声推算所需天数、预先定死成败线）。
2. **给出诚实读数**：用能识破安慰剂 / 均值回归 / 数据不足的读数引擎，给出
   **有效 / 数据不足 / 疑似安慰剂** 的结论——并且**对大多数建议敢说「没证据」**。

它不是又一个「推送建议」的助手，而是建议的**验证层**：从「让你相信有用」转为「向你证明是否有用」。

## 三个页面

1. **实验设计台**：3 条来自健康助手的 mock 建议 → 选一条看验己生成的实验协议。
2. **读数**：回放基线/干预的每日数据（柱状图）+ 诚实结论卡（含个人证据强度、判定依据）+
   「朴素解读 vs 验己诚实读数」的 before/after 并排对比。
3. **实验档案**：三场实验的诚实结论一览 + 「什么对你真有效 / 什么其实是噪声」的个人证据库。

三场预置实验覆盖读数的三种典型结论：

| 建议 | 主指标 | 结论 | 为什么 |
| --- | --- | --- | --- |
| 少吃夜宵 | 静息心率↓ | 数据不足 | 改善(2bpm)小于基线波动(±3bpm)，且基线本就在下行 → 疑似均值回归 |
| 睡前补镁 | 深睡时长↑ | 有效 | ABAB 两轮复现，效应约为基线波动 3.6 倍 |
| 冷水澡 | 主观精力↑ | 疑似安慰剂 | 改善集中在第 1 周、第 3 周回落到基线，且为未盲主观自评 → 新奇效应 |

## 本地运行

```bash
npm install      # 安装依赖
npm run dev      # 本地开发（默认 http://localhost:5173）
npm run build    # 生产构建，产物在 dist/
npm run preview  # 预览构建产物
```

## 技术说明

- 技术栈：Vite 5 + React 18 + TypeScript 5。
- `vite.config.ts` 设 `base: './'`（相对路径），可部署到任意 GitHub Pages 子目录。
- 读数引擎在 `src/logic/engine.ts`：确定性计算基线均值/波动、效应量、ABAB 反转一致性、
  均值回归与新奇效应启发式 → 结论 + 0–100 个人证据强度 + 判定依据。全部数字可复现。
- mock 数据在 `src/data/experiments.ts`。

## 明确不做

- 不接入真实健康数据（手环 / CGM / 血检）、不登录、不连数据库 / 支付 / 外部 API / LLM。
- 不提供医疗诊断或医疗建议。
- 读数引擎是确定性统计替身，不声称是真实 AI 推断。

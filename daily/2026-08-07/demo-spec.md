# Demo 设计说明 — 2026-08-07

## 1. Demo 名称

归位 Guīwèi — 长任务 Agent 复跑前的「世界重校安检台」

## 2. 一句话定位

在长任务 Agent 按 append-only 日志「原地续跑」之前，先把「它记得的世界(T0)」与「现在的世界(T1)」并排对齐、逐条算漂移、裁决该不该续——**回放还原 Agent，归位还原「续跑是否安全」**。

## 3. 目标用户

把长时程（数小时~24h）自主 Agent 推向生产的平台方与工程团队：编码 Agent、迁移/运维 runbook Agent、数据回填 Agent。

## 4. 使用场景

一个迁移 Agent「MigrateBot」在执行 42 步的多仓依赖升级 + 配置迁移 runbook，跑到第 27 步时崩溃暂停；18 小时后要从事件日志原地续跑。续跑前，归位对它当初的世界假设逐条复核。

## 5. Demo 策略分型（重要）

- 本机会属于：☑ 抽象 / CLI / API / 基础设施类产品（Agent 运行时安检层）
- 采用的演示方式：纯前端「**模拟体验 + 价值可视化**」——
  - **模拟续跑控制台**：脚本化重放「崩溃→18h→续跑」这段工作流；
  - **假设账本（可搜索/可展开）**：对每条世界假设做 T0 vs T1 对照与证据下钻；
  - **before / after 对比**：朴素回放（盲目续跑造成事故） vs 归位安检后复跑（改写计划、避坑），把增量价值直接摊给用户看。
- 演示的是**我们分析出的创新切入点**（复跑前世界重校），不是 Muse Code 的克隆（它是编码 Agent + 恢复引擎，卖点是「无缝续」；我们卖点相反，是「敢喊停」）。

## 6. 核心流程（用户 3 分钟内看懂价值）

1. **复跑总览**：看到暂停中的长任务卡片——任务名、进度 27/42、暂停原因（崩溃）、时间缺口 18h22m，以及两个入口按钮：「① 直接按日志复跑（朴素回放）」「② 先过归位安检」。
2. **世界重校**：进入假设账本，逐条看「Agent 记得(T0)」vs「现在(T1)」、漂移状态（一致 / 漂移 / 已失效）、严重度与裁决动作；点开任一条看证据（日志摘录 + live probe 结果）。顶部有一条「归位裁决」汇总条，随可交互开关实时重算。
3. **复跑简报 & 影响对比**：左「朴素回放」的事故清单（重复合并 PR / 覆盖他人改动 / 二次迁移损坏数据 / 追死目标），右「归位安检后」的安全改写计划；中间一排指标（避免高危动作数 / 需人工确认 / 自动可续步 / 预计省下的返工）。

## 7. 页面结构（<= 3 个主要页面）

采用单页 + 顶部三段式导航（① 复跑总览 · ② 世界重校 · ③ 复跑简报），共 3 个主要视图：

- 视图 1「复跑总览」：任务卡 + 价值主张 + 两个复跑入口。
- 视图 2「世界重校」：假设账本（核心）+ 归位裁决汇总 + 证据下钻 + 「反事实开关」。
- 视图 3「复跑简报」：before/after 事故对比 + 指标条 + 可导出的复跑简报文本。

## 8. 关键交互

- **反事实开关**：用户可翻转个别世界事实（如「假装 PR #812 其实没被合并」），假设账本的漂移状态、严重度与顶部裁决**实时由确定性引擎重算**——让用户直观确认「这是逻辑，不是写死的文案」。
- **假设条展开**：点击任一假设，展开 T0 日志摘录（假设从何而来）+ T1 live probe（现在探到什么）+ 引擎给出的裁决理由。
- **视图切换保持状态**：反事实开关的改动在三个视图间一致联动（总览统计、账本、简报三处同步）。

## 9. 使用的 mock 数据

全部为 mock，不接真实后端 / 外部 API：

- `src/data/scenario.ts`：任务元信息（名称、42 步、暂停在 27、缺口时长）、T0「Agent 记得的世界」快照、T1「现在的世界」快照、每条假设的日志摘录与 live probe 文案、每条假设影响哪些后续步骤。
- 假设涵盖 7 类真实漂移：repo HEAD 前移、PR 被他人合并、config flag 被 oncall 改、CI 由绿转红、DB migration 已被别的流程应用、依赖版本未变（对照「一致」）、目标 ticket 被关成 won't-fix。
- `src/logic/reconcile.ts`：确定性引擎——比较 T0/T1、判定漂移状态与严重度、映射到裁决（续/重规划/人工确认/跳过/中止）、汇总统计与 before/after 影响。数据结构化，非硬编码字符串。

## 10. 明确不做什么

- 不做登录 / 用户系统。
- 不接数据库 / 支付 / 外部私钥 / 真实 API / LLM。
- 不真的读取任何 Git/CI/DB——所有 T0/T1 世界快照均为 mock，Demo 内会明确标注「模拟」。
- 不做生产级后端；不超过 3 个主要视图；全部数据 mock。

## 11. 成功体验标准

- 用户 3 分钟内能说出：**它解决什么**（长任务续跑前，世界可能已漂移，盲目续跑会出事）、**怎么用**（看假设账本 + 裁决，翻反事实开关重算）、**增量在哪**（before/after 事故对比 —— 归位避免了朴素回放会造成的高危动作）。
- 首屏一眼看懂「回放还原 Agent，归位还原『续跑是否安全』」这句差异化主张。

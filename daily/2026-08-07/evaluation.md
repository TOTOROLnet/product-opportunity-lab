## 7. Demo 的最大问题

- 场景与漂移判级为 mock：真实产品需从**异构** Agent 日志抽取「世界假设」并为每类假设写 live probe（Git/PR/CI/DB/config/工单各一套适配器），工程量不小；Demo 用确定性引擎 + mock 规避，界面已明确标注「模拟」，但仍需读者理解这是价值可视化而非成品。
- 场景为单例（一个迁移任务）；要更有说服力，未来可加入多类长任务模板（编码 Agent / 数据回填）。

## 8. 是否建议用户人工体验

**建议。** 交互式「反事实开关 + before/after 对比」是本 Demo 的价值高光，静态截图无法完全传达；打开在线 Demo 勾选几下即可直观感到「续跑前校一眼世界」的价值。

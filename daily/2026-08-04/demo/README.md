# 有数 Yǒushù · 诚实的端侧实时动作教练（Demo）

> 2026-08-04 产品机会实验室 · 纯前端静态原型（Vite + React + TypeScript）

一个把 **「感知置信度」而非「纠错覆盖率」** 做成第一原则的端侧 CV 健身教练：
**看得见才教、看不清就明说且不瞎数不瞎纠、动作垮了就喊停**——用诚实与剂量，替代同类的数满与讨好。

本 Demo 演示的是我们分析出的**创新切入点（可信度优先）**，与被参考产品 CoachAI（覆盖率导向：数每一次、实时纠每一次）**目标函数相反**，不是克隆。

## 为什么做这个

上游 radar 报告（2026-08-04）里 CoachAI（13/18）用手机摄像头实时数次数、纠姿势；
报告自己点破它的**生死线**是「CV 纠错的准确度与体感」+「健身应用留存天然差」。
我们的判断：现有同类把「实时反馈」等同于「不停地数、不停地纠、不停地夸」，
但摄像头会被机位/遮挡/速度限制——**看不清却自信乱纠 = 教你错误发力甚至受伤**；
把硬撑的垃圾次数也数进去还夸你 = 让你把水分当进步。
有数 用**逐次置信度、只认可信次数、疲劳喊停**补上这段被集体回避的空白。

## 三个页面（3 分钟看懂价值）

1. **① 实练台**：点「开练」，SVG 骨架逐次做深蹲；实时显示「看得清吗」置信度条与逐次教练判定——
   达标 ✓ / 姿势提醒（含哪块关节、为什么）/ **「我看不清，先调机位」（不计数、不瞎纠）** /
   到疲劳那一下 **喊停**。计数器只加真正看清并达标的次数。
2. **② 讨好 vs 有数**：同一组 12 次并排对照——讨好型数满 12、对 3 次看不清的也自信乱纠、从不喊停；
   有数只认看清的、明说看不清、第 9 次喊停。下方汇总关键统计。
3. **③ 诚实进度**：一周汇总——每天「以为的次数 vs 可信次数」的水分条 + 深度中位数趋势折线 + 一段诚实读数。

## 运行方式

```bash
npm install     # 安装依赖
npm run dev     # 本地开发（默认 http://localhost:5173）
npm run build   # 生产构建，产物在 dist/
npm run preview # 预览构建产物
```

## 技术说明

- 技术栈：Vite + React 18 + TypeScript。`vite.config.ts` 设 `base: './'`，可部署到任意 Pages 子目录。
- **确定性引擎** `src/logic/engine.ts`：逐 rep 置信度判定、达标/看不清/纠正、疲劳喊停点、
  讨好 vs 有数 对照统计、一周聚合与诚实读数。所有数字由引擎算出（已用一次性脚本预校验），非手写。
- **全部 mock**：`src/data/sessions.ts` 是脚本化的逐次关节数据，**模拟**端侧 CV 输出；
  骨架姿态由深度/内扣参数 + 动画相位参数化生成，**非录制视频**。
- **不做**：不开真实摄像头、不接 CV 模型 / LLM / 后端 / 数据库 / 登录 / 支付 / 外部 API。
  「视频不出本机」在 Demo 里是叙事，不涉及任何真实数据流。
